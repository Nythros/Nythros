# 软件包划分方案

Composer Monorepo + path repository 管理。开发时本地路径自动解析，无需发布 Packagist。

## 1. 划分原则

- **按架构分层**：Runtime Kernel、World、Entity、Actor、AOI、Event 各自成包，与 `01-架构规范.md` 的分层一一对应。
- **接口与实现分离**：`nythros/contracts` 只放接口；内核的抽象实现与 Workerman 绑定实现分开（`nythros/kernel` / `nythros/kernel-workerman`、`nythros/network` / `nythros/network-workerman`）。
- **依赖方向由外到内**：Framework → Engine 实现 → Contracts。所有包依赖 `nythros/contracts`，不允许反向。
- **初期允许合并**：kernel+scheduler、entity+actor 可以合并，核心稳定后再拆。

## 2. 包清单

| 包名 | 职责 | 类型 |
|---|---|---|
| `nythros/contracts` | 全部核心接口定义 | 接口 |
| `nythros/kernel` | Runtime Kernel 抽象实现（不绑定具体事件循环） | 抽象实现 |
| `nythros/kernel-workerman` | 基于 Workerman 的 Kernel 实现 | 绑定实现 |
| `nythros/scheduler` | Scheduler 抽象与基础实现（TickScheduler / TimerWheel / TaskQueue） | 抽象实现 |
| `nythros/world` | World 聚合根（组装 EntityManager、ActorSystem、MapManager、RegionScheduler） | 核心实现 |
| `nythros/entity` | Entity 基础实现（BaseEntity、Position） | 核心实现 |
| `nythros/actor` | Actor 基础实现（BaseActor、SimpleActorSystem） | 核心实现 |
| `nythros/aoi` | 空间索引与 AOI 基础实现（GridAOI） | 核心实现 |
| `nythros/event` | EventBus 基础实现（SimpleEventBus） | 核心实现 |
| `nythros/network` | 传输层抽象接口 | 接口 |
| `nythros/network-workerman` | WebSocket / TCP 传输实现 | 绑定实现 |
| `nythros/protocol` | Message / Serializer / Frame 抽象 | 接口 |
| `nythros/security` | Authenticator / Session / Identity 接口 | 接口 |
| `nythros/persistence` | 存储接口 | 接口 |
| `nythros/framework` | 轻量游戏框架（BaseActor / BasePlayer / BaseMonster / BaseNPC + 插件机制） | 框架 |
| `nythros/demo` | 示例项目 | 示例 |

## 3. 依赖关系

```text
nythros/demo
   ├── nythros/framework
   │      ├── nythros/world
   │      │      ├── nythros/entity
   │      │      ├── nythros/actor
   │      │      ├── nythros/aoi
   │      │      ├── nythros/event
   │      │      └── nythros/scheduler
   │      │              └── nythros/kernel
   │      ├── nythros/network
   │      ├── nythros/protocol
   │      └── nythros/security
   ├── nythros/kernel-workerman
   │      └── nythros/kernel
   └── nythros/network-workerman
          └── nythros/network

所有包最终依赖 nythros/contracts。
```

各包依赖列表：

- `nythros/contracts`：仅 `php >= 8.3`。
- `nythros/kernel`：`nythros/contracts`。
- `nythros/scheduler`：`nythros/contracts`、`nythros/kernel`。
- `nythros/entity`、`nythros/actor`、`nythros/aoi`、`nythros/event`：`nythros/contracts`。
- `nythros/world`：`nythros/contracts`、`nythros/entity`、`nythros/actor`、`nythros/aoi`、`nythros/event`、`nythros/scheduler`。
- `nythros/network`、`nythros/protocol`、`nythros/security`、`nythros/persistence`：`nythros/contracts`。
- `nythros/kernel-workerman`：`nythros/kernel` + workerman。
- `nythros/network-workerman`：`nythros/network` + workerman。
- `nythros/framework`：`nythros/world`、`nythros/actor`、`nythros/entity`、`nythros/network`、`nythros/protocol`、`nythros/security` 的抽象。
- `nythros/demo`：`nythros/framework` + `nythros/kernel-workerman` + `nythros/network-workerman`。

## 5. composer.json 示例

根 composer.json（path repository 指向 `packages/*`）：

```json
{
    "name": "nythros/monorepo",
    "type": "project",
    "require": {
        "php": ">=8.3",
        "nythros/demo": "@dev"
    },
    "repositories": [
        {
            "type": "path",
            "url": "packages/*"
        }
    ],
    "minimum-stability": "dev",
    "prefer-stable": true
}
```

> 根包 `nythros/monorepo` 是私有开发根，不发布 Packagist；对外发布的是各子包。

子包 composer.json 统一模板（以 `nythros/contracts` 为例，PSR-4 命名空间 `Nythros\Contracts\` 指向 `src/`）：

```json
{
    "name": "nythros/contracts",
    "type": "library",
    "require": {
        "php": ">=8.3"
    },
    "autoload": {
        "psr-4": {
            "Nythros\\Contracts\\": "src/"
        }
    }
}
```

依赖其他包的子包示例（以 `nythros/entity` 为例）：

```json
{
    "name": "nythros/entity",
    "type": "library",
    "require": {
        "php": ">=8.3",
        "nythros/contracts": "@dev"
    },
    "autoload": {
        "psr-4": {
            "Nythros\\Entity\\": "src/"
        }
    }
}
```

各包命名空间：`Nythros\Kernel\`、`Nythros\Scheduler\`、`Nythros\World\`、`Nythros\Entity\`、`Nythros\Actor\`、`Nythros\Aoi\`、`Nythros\Event\`、`Nythros\Network\`、`Nythros\Protocol\`、`Nythros\Security\`、`Nythros\Persistence\`、`Nythros\Framework\`、`Nythros\Demo\`，均指向各自 `src/`。

## 6. Contracts 包接口清单

`nythros/contracts` 承载 v0.1 的全部核心接口（与 `01-架构规范.md` 第 10 章一致）：

| 接口 | 方法 |
|---|---|
| `ClockInterface` | `tick()` / `now()` |
| `SchedulerInterface` | `addTask()` / `runFrame()` |
| `WorldInterface` | `getEntityManager()` / `getActorSystem()` / `getAOI()` / `getEventBus()` |
| `EntityInterface` | `getId()` / `getPosition()` |
| `ActorInterface` | `update()` |
| `EntityManagerInterface` | `add()` / `remove()` / `get()` / `all()` |
| `ActorSystemInterface` | `add()` / `updateAll()` |
| `AOIProviderInterface` | `updateEntity()` / `query()` |
| `EventBusInterface` | `publish()` / `subscribe()` |

后续阶段的接口（Network / Protocol / Security / Persistence）也在 contracts 中定义，具体实现包各自落地。

## 7. 版本策略

- v0.1 阶段所有包版本 `0.1.x`，不承诺向后兼容。
- 开发期通过 path repository 本地解析，不发布 Packagist。
- 根包 `nythros/monorepo` 是私有开发根，不发布 Packagist；对外发布的是各子包。
- 核心稳定后（Engine v1.0），`nythros/contracts`、`nythros/kernel`、`nythros/world` 等核心包各自独立发布 Packagist。

## 8. 后续演进

接口保持稳定，实现可替换，形成可插拔的 Engine 生态：

| 抽象 | 可替换实现包 |
|---|---|
| Kernel 事件循环 | `nythros/kernel-workerman`、`kernel-swoole` |
| 传输层 | `nythros/network-workerman`、`network-swoole` |
| AOI | `nythros/aoi`（Grid）、`aoi-quadtree`、`aoi-radius` |
| 协议序列化 | `protocol-msgpack`、`protocol-protobuf`、`protocol-flatbuffers` |
| 安全认证 | `security-redis-token`、`security-jwt` |
| 持久化 | `persistence-mysql`、`persistence-mongodb` |

业务层只依赖接口，替换实现不需要改动业务代码。
