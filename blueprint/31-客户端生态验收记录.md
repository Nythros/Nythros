## 一、交付内容

### 1.1 SDK 自动重连（nythros-client.js）

| 项 | 说明 |
|---|---|
| 开关与参数 | `autoReconnect`（缺省 false 向后兼容）/ `maxReconnectAttempts`（缺省 5）/ `reconnectDelayMs`（缺省 2000，指数退避 ×2^n 上限 30s）。 |
| 重连链路 | 整链重登：gateway 重签 token → Map 重连 attach——**重连即同图迁移**（P15 语义）：服务端在 detach 时自动导出转移票据，重连 attach 原子消费恢复位置/血量/背包；用户主动 `close()` 不触发（closedByUser 守卫 + 重连定时器取消）。 |
| 本地合成事件 | `:reconnecting` / `:reconnected` / `:reconnectfailed`（经 handlers 派发，非线上帧）；重连成功清空实体表（attach 后由视野快照全量重建，state-sync 口径）。 |

### 1.2 npm 包化 + TS 类型生成

- `packages/client-js/package.json`：`@nythros/client` v0.1.0——main/types/files/engines（node ≥22）、
  零依赖；未发布 registry，本地路径安装可用（`npm install <repo>/packages/client-js`）。
- `scripts/generate-definitions.php` + 生成物 `nythros-client.d.ts`：码表段（FrameCodeTable/PayloadCodeTable
  interface + FrameName/PayloadKeyName 字面量联合）从 PHP `codeMap()` 程序化渲染（88 帧/83 字段），
  运行时类（NythrosClient/NythrosCodec/NythrosInterpolator）为手写模板段——**生成文件勿手改**，
  同步铁律与 JS SDK 一致（改 PHP 枚举后重新生成）。

### 1.3 图形化示例客户端（examples/mmorpg-canvas.html）

单文件浏览器页面（零构建）：登录表单 → canvas 2D 渲染——网格 + 实体圆点（自己绿/玩家蓝/怪物红）+
相机跟随自身 + HUD（entityId/权威位置/hp）；WASD/方向键/点击移动；攻击最近怪物按钮；
state-sync 铁律落地：渲染读 `sample()`、判定读 `position()`；autoReconnect 状态上屏。

## 三、边界与后续

- 重连期间进行中的 request 全部 reject（pending 清空）——调用方需自行重试；重连成功后的
  「请求重放」（离线队列）不做（服务端无幂等登记，可能重复扣费类路由有风险）。
- canvas demo 未接 chat/guild 等社交帧，未做预测回滚（服务器权威模型边界，blueprint/21 §1.2）。
- npm 正式发布（registry publish + CI 打包）留待有外部消费方时处理。
