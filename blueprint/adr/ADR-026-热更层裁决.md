# ADR-026 · 热更层裁决：不做脚本热更（P17）

- 状态：**已裁决（Decided）——不立项**，随 P17 批（blueprint/29 记录）
- 日期：2026-08-29
- 关联：ADR-020（三层产品定位）、blueprint/21 P17、blueprint/24（P11 配置热载基线）、blueprint/28（P16 rolling/drain 部署面）

## 1. 待决问题

是否为玩法逻辑引入脚本热更层？blueprint/21 P17 列了三个候选：
**Lua embed** / **PHP DSL（规则引擎）** / **仅配置热载**。

## 2. 需求拆解（先问「热更到底要热什么」）

| 真实需求 | 现状 | 结论 |
|---|---|---|
| 数值/内容调参（掉率、怪物表、技能倍率、任务链） | **P11 已交付**：三表经 ConfigRepository 挂载 + ConfigSchema 校验 + mtime 热载（坏表回滚） | **已满足** |
| 玩法逻辑变更（新技能行为、新规则） | 代码发布：测试 + CI 四门禁 + **P16 drain/rolling**（标记 draining → 存量玩家归零 → 摘除换新） | 分钟级发布，无需脚本层 |
| 紧急止血（线上事故秒级干预） | GM 命令面（gm:exec：status/broadcast/kick/drain）+ 配置热载开关 | **已满足**（可按需扩 GM 命令） |
| 不可信方提供玩法脚本（UGC/多租户） | 无此需求（单团队开发） | 不存在 |

## 3. 候选方案评估（含网游行业先例）

### 3.1 Lua embed

- **行业先例**：Lua 热更是 C/C++ 游戏服（skynet、OpenResty 生态、早期网易系）的主流方案——前提是
  **宿主语言与脚本边界清晰**（C 栈暴露 API 给 Lua）。
- **PHP 现实**：ext-lua 停留在 PHP 7 时代无维护；luaSandbox（Wikimedia）为进程内沙箱但 PHP↔Lua
  数据桥接成本高、无异步/事件语义；跨语言方案（独立 Lua 进程 + IPC）等于引入第二运行时。
- **工程代价**：双工具链（phpstan/CS-Fixer/PHPUnit 全部不覆盖 Lua 侧）、跨语言调试断点、
  沙箱逃逸面（不可信脚本场景才有收益，本仓库无）、性能边界（每次跨 VM 调用的序列化）。
- **裁决**：**否决**——代价与收益完全失衡，且「逻辑热更」的真实频率撑不起常驻第二运行时。

### 3.2 PHP DSL（规则/公式引擎）

- **行业先例**：技能/公式 DSL 在数值策划密集的项目常见（如自研条件表达式求值器）。
- **评估**：P11 的声明式表已承载「参数化玩法」；DSL 的增量价值是「逻辑组合」（条件分支、序列），
  但自研 DSL 是**永久性语言维护负担**（语法/语义/报错/文档/工具），表达力天花板低，复杂逻辑
  最终还是要回 PHP——届时出现「一半 DSL 一半代码」的更差形态。
- **裁决**：**否决**——等出现真实的「策划自主组合逻辑」需求且规模可量化时再评估；当前用
  SkillDefinition 式的**声明式参数行**（表驱动 + 装配期校验）覆盖，新增玩法行不改引擎代码。

### 3.3 仅配置热载 + rolling 发布（采纳）

- 配置热载（P11）承载内容与数值的热迭代；
- 逻辑迭代走 **drain → rolling**（P16 的 GM drain + map-rolling watch 模式）：分钟级、连接无损
  （ draining 拒新不拒旧）、全程有测试与门禁背书——这正是 PHP 游戏服生态的经典答案
  （Workerman 常驻 + 优雅重载，社区多年实践）；
- 需要秒级干预的事故场景由 GM 命令面兜底（可扩展）。

## 4. 裁决

**不做脚本热更层**（Lua embed 与 PHP DSL 均否决）；「配置热载 + rolling 发布 + GM 命令」三件套
构成热更需求的完整覆盖。architecture.md §7 的开放决策「~~热更新~~（仅配置表热载）」由本 ADR
正式关闭并补充裁决理由。

## 5. 重启条件（满足其一方可重新立项）

1. 运营侧出现**分钟级玩法逻辑迭代**的硬需求，且 rolling 发布窗口被证实不可接受（需给出事故记录）；
2. 出现**不可信方提供玩法脚本**的形态（UGC/多租户）——届时裁决「隔离进程 + 受限 DSL」方案，
   而非进程内 embed；
3. PHP 生态出现维护活跃、语义完整的沙箱化脚本扩展（当前无）。

## 6. 影响面

- 零代码变更（裁决性 ADR）。
- blueprint/21 P17 关闭；阶段 C（P15/P16/P17）全部收官。
