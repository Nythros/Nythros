# 启动执行清单

开动代码的第一步：最小可运行骨架。不引入 Workerman、网络、数据库，纯 PHP `while` 循环验证核心架构闭环。

> 本清单中的代码是最小验证实现示意，非最终 API。最终接口以 `01-架构规范.md` 第 10 章与 `02-软件包划分.md` 第 6 章为准。

最小骨架覆盖 Tick 顺序（`01-架构规范.md` 第 9 章）的一部分：Clock tick 由主循环调用，Actor update 与 AOI 更新在 `World::update()` 内按序执行，EventBus flush 由主循环 publish 触发。完整 7 步顺序在引擎接入网络与 RegionScheduler 后全部落地。

## 第 0 步：环境与工具链准备

### 环境检查

- PHP >= 8.3：`php -v`
- Composer 2.x：`composer --version`

阶段 1 为纯 PHP 单进程，不依赖 pcntl / posix / sockets 扩展。阶段 2 引入 Workerman 后，生产运行环境必须是 Linux（Windows 仅限开发调试），需提前准备 WSL / Docker / Linux 机器。

## 第 3 步：kernel 包实现 SystemClock

`packages/kernel/src/SystemClock.php`（命名空间 `Nythros\Kernel`）：

```php
namespace Nythros\Kernel;

use Nythros\Contracts\ClockInterface;

final class SystemClock implements ClockInterface
{
    private float $now = 0.0;
    private float $deltaTime = 0.0;

    public function tick(): void
    {
        $next = microtime(true);
        $this->deltaTime = $this->now > 0.0 ? $next - $this->now : 0.0;
        $this->now = $next;
    }

    public function now(): float
    {
        return $this->now;
    }

    public function deltaTime(): float
    {
        return $this->deltaTime;
    }
}
```

**验收点**：`tick()` 记录 microtime 与 deltaTime，连续 tick 后 `now()` 单调递增。**最小测试**：连续 tick 后 `now()` 单调递增；首次 tick 后 `deltaTime()` 为 0；二次 tick 后 `deltaTime()` > 0。

## 第 4 步：scheduler 包实现 SimpleScheduler

`packages/scheduler/src/SimpleScheduler.php`（命名空间 `Nythros\Scheduler`）：

```php
namespace Nythros\Scheduler;

use Nythros\Contracts\SchedulerInterface;

final class SimpleScheduler implements SchedulerInterface
{
    /** @var array<int, list<callable>> */
    private array $tasks = [];

    public function addTask(callable $task, int $priority = 0): void
    {
        $this->tasks[$priority][] = $task;
    }

    public function runFrame(): void
    {
        krsort($this->tasks);

        $tasks = $this->tasks;
        $this->tasks = [];

        foreach ($tasks as $list) {
            foreach ($list as $task) {
                $task();
            }
        }
    }
}
```

**验收点**：`addTask()` 带优先级；`runFrame()` 按优先级从高到低执行，执行后任务列表清空。**最小测试**：`addTask()` 记录优先级；`runFrame()` 按优先级从高到低执行；执行后任务列表清空。

## 第 6 步：actor 包实现 BaseActor + SimpleActorSystem

`packages/actor/src/BaseActor.php`：

```php
namespace Nythros\Actor;

use Nythros\Contracts\ActorInterface;
use Nythros\Contracts\EntityInterface;

abstract class BaseActor implements ActorInterface
{
    protected ?EntityInterface $entity = null;

    public function bindEntity(EntityInterface $entity): void
    {
        $this->entity = $entity;
    }

    abstract public function update(): void;
}
```

`packages/actor/src/SimpleActorSystem.php`：

```php
namespace Nythros\Actor;

use Nythros\Contracts\ActorInterface;
use Nythros\Contracts\ActorSystemInterface;

final class SimpleActorSystem implements ActorSystemInterface
{
    /** @var list<ActorInterface> */
    private array $actors = [];

    public function add(ActorInterface $actor): void
    {
        $this->actors[] = $actor;
    }

    public function updateAll(): void
    {
        foreach ($this->actors as $actor) {
            $actor->update();
        }
    }
}
```

**验收点**：Actor 可绑定一个 Entity（`bindEntity()`），也可不绑定（`$entity` 允许为 null）；`updateAll()` 遍历执行全部 Actor 的 `update()`。**最小测试**：`bindEntity()` 后 `$entity` 生效、不绑定时为 null；`updateAll()` 遍历执行全部 Actor 的 `update()`。

## 第 7 步：event 包实现 SimpleEventBus

`packages/event/src/SimpleEventBus.php`：

```php
namespace Nythros\Event;

use Nythros\Contracts\EventBusInterface;

final class SimpleEventBus implements EventBusInterface
{
    /** @var array<string, list<callable>> */
    private array $listeners = [];

    public function publish(string $event, array $payload = []): void
    {
        foreach ($this->listeners[$event] ?? [] as $listener) {
            $listener($payload);
        }
    }

    public function subscribe(string $event, callable $listener): void
    {
        $this->listeners[$event][] = $listener;
    }
}
```

**验收点**：`subscribe()` 注册监听器数组；`publish()` 触发全部监听器；未订阅的事件 publish 不报错。**最小测试**：`subscribe()` 后 `publish()` 触发全部监听器；未订阅事件 `publish()` 不报错；payload 透传。

## 第 8 步：aoi 包实现 GridAOI

`packages/aoi/src/GridAOI.php`：

```php
namespace Nythros\Aoi;

use Nythros\Contracts\AOIProviderInterface;
use Nythros\Contracts\EntityInterface;

final class GridAOI implements AOIProviderInterface
{
    /** @var array<string, array<string, EntityInterface>> */
    private array $cells = [];

    public function __construct(
        private readonly int $cellSize,
    ) {
    }

    public function updateEntity(EntityInterface $entity): void
    {
        $this->remove($entity);

        $key = $this->cellKey($entity);
        $this->cells[$key][$entity->getId()] = $entity;
    }

    public function query(EntityInterface $entity): array
    {
        $key = $this->cellKey($entity);
        return array_values($this->cells[$key] ?? []);
    }

    private function remove(EntityInterface $entity): void
    {
        foreach (array_keys($this->cells) as $key) {
            unset($this->cells[$key][$entity->getId()]);
        }
    }

    private function cellKey(EntityInterface $entity): string
    {
        ['x' => $x, 'y' => $y] = $entity->getPosition();

        $cx = (int) floor($x / $this->cellSize);
        $cy = (int) floor($y / $this->cellSize);

        return $cx . ':' . $cy;
    }
}
```

**验收点**：`cellKey` 用 floor 计算 `cx:cy`；`updateEntity` 按格子存储实体（跨格移动先移除旧格）；`query` 返回同格实体集合；Cell 只存 `entities: EntityId[]` 索引，不存任何业务字段。**最小测试**：同格实体可被 `query()` 查到；跨格移动后旧格移除、新格可见；不同格实体互相不可见。

## 第 9 步：world 包实现 World + SimpleEntityManager

`packages/world/src/SimpleEntityManager.php`：

```php
namespace Nythros\World;

use Nythros\Contracts\EntityInterface;
use Nythros\Contracts\EntityManagerInterface;

final class SimpleEntityManager implements EntityManagerInterface
{
    /** @var array<string, EntityInterface> */
    private array $entities = [];

    public function add(EntityInterface $entity): void
    {
        $this->entities[$entity->getId()] = $entity;
    }

    public function remove(string $id): void
    {
        unset($this->entities[$id]);
    }

    public function get(string $id): ?EntityInterface
    {
        return $this->entities[$id] ?? null;
    }

    public function all(): array
    {
        return array_values($this->entities);
    }
}
```

`packages/world/src/World.php`：

```php
namespace Nythros\World;

use Nythros\Contracts\AOIProviderInterface;
use Nythros\Contracts\ActorSystemInterface;
use Nythros\Contracts\EntityManagerInterface;
use Nythros\Contracts\EventBusInterface;
use Nythros\Contracts\SchedulerInterface;
use Nythros\Contracts\WorldInterface;

final class World implements WorldInterface
{
    public function __construct(
        private readonly EntityManagerInterface $entityManager,
        private readonly ActorSystemInterface $actorSystem,
        private readonly AOIProviderInterface $aoi,
        private readonly EventBusInterface $eventBus,
        private readonly SchedulerInterface $scheduler,
    ) {
    }

    public function update(): void
    {
        $this->actorSystem->updateAll();

        foreach ($this->entityManager->all() as $entity) {
            $this->aoi->updateEntity($entity);
        }

        $this->scheduler->runFrame();
    }

    public function getEntityManager(): EntityManagerInterface
    {
        return $this->entityManager;
    }

    public function getActorSystem(): ActorSystemInterface
    {
        return $this->actorSystem;
    }

    public function getAOI(): AOIProviderInterface
    {
        return $this->aoi;
    }

    public function getEventBus(): EventBusInterface
    {
        return $this->eventBus;
    }
}
```

**验收点**：构造函数只接收接口类型（五模块组合）；`update()` 顺序固定为 ActorSystem.updateAll → 遍历 EntityManager.all 调 AOI.updateEntity → Scheduler.runFrame。**最小测试**：`update()` 按固定顺序执行（ActorSystem.updateAll → AOI.updateEntity → Scheduler.runFrame）；`getEntityManager()` / `getActorSystem()` / `getAOI()` / `getEventBus()` 返回注入的实例。

## 第 10 步：demo 包写 run.php

`packages/demo/run.php`：

```php
<?php

declare(strict_types=1);

require __DIR__ . '/../../vendor/autoload.php';

use Nythros\Actor\BaseActor;
use Nythros\Actor\SimpleActorSystem;
use Nythros\Aoi\GridAOI;
use Nythros\Entity\BaseEntity;
use Nythros\Entity\Position;
use Nythros\Event\SimpleEventBus;
use Nythros\Kernel\SystemClock;
use Nythros\Scheduler\SimpleScheduler;
use Nythros\World\SimpleEntityManager;
use Nythros\World\World;

$clock = new SystemClock();
$scheduler = new SimpleScheduler();
$entityManager = new SimpleEntityManager();
$actorSystem = new SimpleActorSystem();
$eventBus = new SimpleEventBus();
$aoi = new GridAOI(cellSize: 10);

$world = new World($entityManager, $actorSystem, $aoi, $eventBus, $scheduler);

$player = new BaseEntity('player-1', new Position(0, 0));
$entityManager->add($player);
$aoi->updateEntity($player);

$eventBus->subscribe('player.moved', function (array $payload): void {
    printf(
        "event player.moved: %s -> (%d, %d)\n",
        $payload['id'],
        $payload['position']['x'],
        $payload['position']['y'],
    );
});

$mover = new class($player) extends BaseActor {
    public function __construct(private readonly BaseEntity $target)
    {
    }

    public function update(): void
    {
        $this->target->move(1, 0);

        ['x' => $x, 'y' => $y] = $this->target->getPosition();
        printf("actor update: %s at (%d, %d)\n", $this->target->getId(), $x, $y);
    }
};
$actorSystem->add($mover);

$frame = 0;
while ($frame < 5) {
    $frame++;

    $clock->tick();
    $world->update();

    $nearby = $aoi->query($player);
    printf("frame %d: nearby entities = %d\n", $frame, count($nearby));

    $eventBus->publish('player.moved', [
        'id' => $player->getId(),
        'position' => $player->getPosition(),
    ]);

    usleep(100000);
}
```

**验收点**：组装五模块 + World；加入一个实体；一个匿名 Actor 每帧 x+1 并输出；订阅 `player.moved`；主循环 5 帧（clock.tick → world.update → aoi.query 输出邻近数 → eventBus.publish → usleep 100000）。
